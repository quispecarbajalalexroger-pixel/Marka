# Marka

Portada de **Marka · Asistencia** (EPC · ELECTROTEL · SGEIM).

Abre la app de marcación con foto (Google Apps Script) a pantalla completa, con logo y nombre propios al instalarla en Android o iPhone, y guarda el acceso del trabajador para que no vuelva a pedir DNI ni PIN.

- Enlace para trabajadores: https://quispecarbajalalexroger-pixel.github.io/Marka/
- Para cambiar el enlace de Apps Script, edita la constante `EXEC` en `index.html`.
